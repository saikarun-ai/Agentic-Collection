vLLM Inference Recipe

The Baidu Unlimited-OCR model ships with DeepSeek-OCR gundam vision stack, capable of processing 40+ pages in a single-pass without memory crashes. Use this pre-packaged python recipe to spin up a local OCR parse server in your stack: 

# Install prerequisites: pip install vllm transformers accelerate torch
from vllm import LLM, SamplingParams

# Initialize Unlimited-OCR engine with standard vision stack
model_id = "baidu/Unlimited-OCR"
llm = LLM(
    model=model_id,
    trust_remote_code=True,
    max_model_len=32768,  # 32K context window for multi-page document
    tensor_parallel_size=1
)

# Formulate prompt for document to structured markdown generation
prompt = "Read and parse this document into highly-structured clean markdown, including all tables, codes, and APIs."
image_path = "./api_screenshot.png"

outputs = llm.generate({
    "prompt": f"<image>\n{prompt}",
    "multi_modal_data": {"image": image_path}
})

print(outputs[0].outputs[0].text)

DevTools Console Shield

By disabling standard browser console-level operations and trapping diagnostic interfaces, we mitigate local payload inspection, token stealing, and client side vulnerability manipulation.

Override Browser Console Logs

Overrides `console.log`, `info`, `warn`, and `error` globally. Intercepts and redirects them to the custom app workspace panel instead.

Intercept Right-Click & Inspect Shortcuts

Blocks Mouse Right-Click context menus, F12 inspector launch, Ctrl+Shift+I, and typical browser inspector hotkeys.

Anti-Debugging Interval Trapping
